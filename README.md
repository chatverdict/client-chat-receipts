# Client Chat Receipts

Free, browser-only tool. Load a WhatsApp chat export (.txt) and get a dated list of lines that look like approvals, change requests, deadlines and payment mentions, with CSV download and print.

Live: https://chatverdict.github.io/client-chat-receipts/

- Runs in the browser. The chat file is read locally and its contents are not sent anywhere.
- The page only reports anonymous visit and "file processed" counts.
- Keyword matching for English messages. It can miss things and flag unrelated lines. It is not legal advice or proof of anything.
- Related: https://chatverdict.github.io/rental-chat-timeline/ (same engine, for tenants and landlords).
